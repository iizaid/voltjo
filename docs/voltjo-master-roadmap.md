# خطة العمل الشاملة لمشروع VoltJo (Master Roadmap)

هذا الملف يحتوي على الخطة المحكمة والدقيقة لجميع الميزات المتبقية (Missing Features) التي يجب إنجازها للوصول بمشروع **VoltJo** إلى مرحلة الإطلاق النهائي (Production). تم تقسيم الخطة إلى مراحل منطقية لضمان التسلسل الصحيح في التطوير.

---

## المرحلة الأولى: دمج الواجهة الخلفية للمساعد الذكي (AI Backend Integration)
تعتبر هذه المرحلة الأهم حالياً لإنهاء العمل على واجهة `/assistant`.

- [ ] **إنشاء نقطة اتصال الخادم (API Endpoint):**
  - [ ] إنشاء ملف `app/api/chat/route.ts` للتعامل مع الطلبات.
  - [ ] بناء نظام يقرأ من `simulateChatResponse` بشكل مؤقت عبر السيرفر كخطوة أولية.
- [ ] **ربط مزود الذكاء الاصطناعي (AI Provider):**
  - [ ] إعداد مفاتيح API (مثل OpenAI أو OpenRouter) في البيئة المحلية `.env.local` فقط.
  - [ ] كتابة `system-prompt.ts` يحتوي على شخصية המساعد وقوانينه (الرد باللهجة الأردنية، استخدام الدينار الأردني، الخ).
- [ ] **تفعيل البث المباشر للردود (Streaming):**
  - [ ] تحويل الاستجابة في الـ API إلى `Server-Sent Events` (SSE).
  - [ ] ربط واجهة الدردشة لاستقبال النصوص بشكل تتابعي (Chunk-by-chunk) لدعم سرعة الاستجابة.
- [ ] **قاعدة المعرفة المخصصة للسيارات (RAG):**
  - [ ] تجهيز ملفات أو جداول تحتوي على معلومات السيارات والمقابس (GB/T و Type 2) وتمريرها للمساعد لمنع الهلوسة.

---

## المرحلة الثانية: قاعدة بيانات سيارات الأردن الأساسية (Core Vehicle Platform)
بناء المحرك الأساسي الذي سيعتمد عليه الموقع لتقديم خدمات المقارنة وعرض السيارات.

- [ ] **تصميم جداول قاعدة البيانات (Supabase Schema):**
  - [ ] إنشاء جدول `vehicles` (النوع، الطراز، سعة البطارية، المدى، قوة المحرك).
  - [ ] إنشاء جدول `pricing` لأسعار السيارات (وكالة مقابل استيراد شخصي "حرة").
- [ ] **برمجة واجهات عرض السيارات:**
  - [ ] بناء صفحة البحث والفلترة المتقدمة للسيارات.
  - [ ] بناء صفحة تفاصيل السيارة `app/vehicles/[id]/page.tsx` لعرض المواصفات كاملة والصور.
- [ ] **تطوير محرك المقارنة (Comparison Engine):**
  - [ ] واجهة تتيح للمستخدم اختيار من سيارتين إلى 3 سيارات.
  - [ ] لوحة تعرض الفروقات في (السعر، المدى الفعلي، تكلفة الشحن، نوع القابس).
- [ ] **حاسبات التكلفة الأردنية (Calculators):**
  - [ ] برمجة حاسبة شحن تعتمد على شرائح الكهرباء المعتمدة رسمياً في الأردن (مدعوم/غير مدعوم).
  - [ ] حاسبة تكاليف الترخيص والتأمين التقريبية للسيارات الكهربائية.

---

## المرحلة الثالثة: لوحة تحكم المستخدم والميزات المتقدمة (User Dashboard)
تطوير الميزات التي تجعل تسجيل الدخول مفيداً للمستخدم للعودة للمنصة.

- [ ] **ربط محادثات الذكاء الاصطناعي بقاعدة البيانات:**
  - [ ] حفظ سجل المحادثات (Chat History) لكل مستخدم في Supabase بدلاً من `localStorage` فقط.
- [ ] **تطوير صفحة التحكم `/dashboard`:**
  - [ ] إضافة قائمة "سياراتي المفضلة" (Saved Cars).
  - [ ] إضافة قائمة "المقارنات المحفوظة" (Saved Comparisons).
- [ ] **أنظمة الدفع والتقارير (اختياري / لاحقاً):**
  - [ ] توليد تقارير شاملة PDF للمقارنات.
  - [ ] تجهيز بوابات الدفع (Stripe) في حال وجود اشتراكات أو خدمات مدفوعة.

---

## المرحلة الرابعة: الحماية والإطلاق للإنتاج (Security & Production Readiness)
الخطوات الأمنية النهائية قبل نشر الموقع للجمهور وتلقي ترافيك حقيقي.

- [ ] **الحماية من استنزاف الموارد (Rate Limiting):**
  - [ ] استبدال نظام الحد المؤقت (In-memory) بنظام موزع مثل `Vercel KV` أو `Redis` لحماية طلبات الـ AI والـ Auth.
- [ ] **مكافحة البوتات (Bot Protection):**
  - [ ] دمج `Cloudflare Turnstile` أو `reCAPTCHA` في نماذج تسجيل الدخول وأي نماذج عامة.
- [ ] **التجهيزات الأمنية النهائية:**
  - [ ] ضبط وتفعيل ترويسات الأمان `Content-Security-Policy (CSP)`.
  - [ ] التأكد من عدم تسرب أي مفاتيح سرية (Service Role Keys) لجهة العميل.
- [ ] **إعدادات البريد الإلكتروني:**
  - [ ] ربط نظام مصادقة Supabase بمزود بريد إلكتروني حقيقي (مثل Resend أو SendGrid) لإرسال رسائل التأكيد واستعادة كلمة المرور.
