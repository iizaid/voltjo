2. FONT AND TYPOGRAPHY FIX
------------------------------------------------------------

The current Arabic font is not good enough.

Firecrawl uses a premium Latin-style font system, but since this product is Arabic-first, use a high-quality Arabic UI font with similar clean geometric quality.

Use one of these fonts:

Preferred:
- IBM Plex Sans Arabic

Alternative:
- Noto Sans Arabic
- Tajawal only if necessary, but IBM Plex Sans Arabic is preferred.

Use a clean Latin fallback for English text and numbers:
- Inter
- Geist Sans
- system-ui

Recommended CSS:
Set the global font stack to:

font-family: "IBM Plex Sans Arabic", "Inter", "Geist", system-ui, sans-serif;

If using Next.js, import the font properly using next/font/google if available:

import { IBM_Plex_Sans_Arabic } from "next/font/google";

Use:
- weights: 400, 500, 600, 700
- subsets: arabic, latin

Typography requirements:
- Hero headline must be large, dark, and confident.
- Use strong font weight for headings.
- Use deep black for main heading.
- Use burnt orange only for the highlighted words.
- Body text should be readable, not too light.
- Small labels should be clean and not blurry.

Suggested Arabic typography scale:
- Hero title desktop: 64px to 76px
- Hero title line-height: 1.15
- Section title: 44px to 56px
- Body text: 18px to 22px
- Nav text: 15px to 16px
- Small labels: 13px to 15px

Use responsive scaling for mobile.

Do not use default browser Arabic fonts.

3. BACKGROUND SYSTEM FIX
------------------------------------------------------------

The page must have a Firecrawl-inspired technical background.

Create a reusable component:

components/background/TechnicalBackground.tsx

This component should render subtle background details across the landing page.

The background should include:
- Very light grid lines
- Large faint rectangular technical panels
- Small dot clusters
- Very subtle circuit-like lines
- Low-opacity battery / plug / route-inspired shapes if needed
- Tiny coordinate-like details
- Soft radial glow in burnt orange, very low opacity
- No loud illustrations
- No colorful gradients
- No dark backgrounds

The background must be visible but extremely subtle.

Recommended background style:
- main background: #ffffff
- grid line: rgba(0,0,0,0.035)
- panel border: rgba(0,0,0,0.055)
- orange accent line/dot: rgba(255,106,0,0.20)
- decorative elements opacity: 0.08 to 0.18 maximum

The background should appear behind all sections:
- Hero
- Supported brands
- Calculator section
- AI assistant section
- CTA/footer area

Do not create a separate random background for every section. Use one consistent system.

Implementation idea:
Use absolute positioned divs with CSS backgrounds:
- linear-gradient for grid
- radial-gradient for subtle orange glows
- SVG-like lines using pseudo elements or simple div borders
- small dotted patterns using background-image radial-gradient

Example:
background-image:
linear-gradient(rgba(0,0,0,0.035) 1px, transparent 1px),
linear-gradient(90deg, rgba(0,0,0,0.035) 1px, transparent 1px);

Use background-size around 96px 96px or 112px 112px.

Add a few floating technical panels:
- rounded rectangles with faint border
- hidden on small screens if needed
- pointer-events-none
- aria-hidden

Important:
The background should not reduce text readability.
