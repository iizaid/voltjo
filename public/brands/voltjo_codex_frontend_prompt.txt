# VoltJo Frontend Landing Page Build Prompt for Codex AI

You are an expert senior frontend engineer and product designer. Your task is to build the first static frontend version of the VoltJo website.

VoltJo is an Arabic-first Jordan-focused Micro SaaS platform for EV and hybrid vehicle intelligence. The platform helps people in Jordan choose the right electric or hybrid car, compare supported models, estimate charging/ownership costs, and use a specialized AI assistant trained/grounded on the cars and market information supported by the platform.

Do NOT build backend logic.

Only build the static website pages and UI sections based on the provided visual references.

- White technical SaaS background.
- Subtle geometric/grid/circuit-like patterns.
- Clean centered layout.
- Premium spacing.
- Strong dark typography.
- Controlled orange accent.
- Soft borders.
- Rounded large containers.
- Smooth UI details.
- Minimal but highly intentional sections.
- No noisy gradients.
- No generic AI startup clichés.

Do NOT copy Firecrawl branding, text, logos, or exact assets. Only use the structural and visual design language: white technical background, top announcement bar, navigation style, technical grid patterns, smooth cards, subtle borders, and premium SaaS rhythm.
